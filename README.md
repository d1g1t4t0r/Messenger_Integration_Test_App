# О проекте
Данный проект является тестовым заданием. Представляет из себя пользовательский интерфейс для отправки и получения сообщений в мессенджер MAX.

В проекте применен GREEN API для мессенджера MAX, потому для использования приложения требуется иметь соответствующую учетную запись и инстанс для мессенджера MAX с корректно установленными параметрами (подробнее [тут](https://green-api.com/v3/docs/before-start/)).

# Запуск
Для локального запуска необходимо иметь npm на Вашем устройстве. Далее:
1) Склонировать репозиторий к себе на устройство;
2) Выполнить команду "npm install";
3) Проверить, совпадает ли Ваш apiUrl в инстансе GREEN API с представленным в файле [config.ts](https://github.com/d1g1t4t0r/Messenger_Integration_Test_App/blob/main/src/config.ts). При несовпадении замените на корректный для Вас;
4) Запустите проект командой "npm run dev".

# Использование
1) На первом экране от пользователя требуется ввести данные инстанса (idInstance и apiTokenInstance). В случае ввода некорректных данных пользователь получает ошибку и предложение ввести снова). В случае корректных данных производится переход на следующий экран;
2) На втором экране пользователь может удалить сохраненные данные инстанса при нажатии кнопки "Выйти", а также ввести номер телефона человека, с которым предполагается начать чат. Если номер введен некорректно, пользователь получает ошибку. Если номер корректен, но аккаунта в MAX нет (или предполагаемый собеседник запретил искать себя в мессенджере по номеру телефона), то пользователь получит соответствующее сообщение. Если номер корректен и аккаунт существует, то пользователь переходит на страницу чата;
3) На странице чата в верхней части экрана пользователь может выйти из чата по нажатии на стрелку в левом верхнем углу. Также он видит имя аккаунта собеседника и его номер телефона возле кнопки выхода. В нижней части экрана пользователь видит поле для ввода сообщений (и кнопку отправки, когда в поле введен текст). Остальную часть экрана занимает чат в виде входящих и исходящих сообщений. После ввода текста в поле для ввода отправить сообщение можно при нажатии на клавиатуре кнопки Enter (Shift+Enter производит перенос строки) или при нажатии на кнопку отправки в интерфейсе.

# Уточнение
В связи с ТЗ подразумевается, что каждый сеанс чата новый, потому даже при наличии в самом мессенджере MAX существующего непустого диалога пользователя с собеседником в текущем веб-приложении история прошлой переписке не отражается.
Также в данном приложении предполагается только отправка и получение текстовых сообщений, потому изображения, видео, голосовые сообщения, а также звонки не поддерживаются.
